# Figma Button Lab: Alerts Button

React + Vite implementation of the Alerts button, with the three layered strokes,
blend modes, inner shadows, inline SVG bell and CSS dot.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

**Vercel:** import the repo. Framework Preset: Vite. Build command `npm run build`, output directory `dist`.

**GitHub Pages:** run `npm run build`, then publish the `dist` folder
(for example with the `gh-pages` branch or a GitHub Actions Pages workflow).
